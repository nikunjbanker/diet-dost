# GitHub Copilot Adapter

For every UI/UX task, follow the repository's `design-system-enforcer` skill.

`DESIGN.md` is the UI/UX source of truth.

Before creating or modifying UI:
- read `DESIGN.md`;
- inspect existing components and tokens;
- reuse existing components;
- avoid arbitrary visual values;
- preserve functionality;
- consider responsive behavior and accessibility;
- verify the implementation.

These rules apply to both new and ongoing development.

Do not duplicate the full skill in this instruction file.
