# Antigravity Adapter

For every UI/UX task, apply the repository's `design-system-enforcer` skill.

Before modifying UI:
- locate and read `DESIGN.md`;
- inspect existing design tokens and reusable components;
- follow the skill for implementation and verification.

This applies to both new development and ongoing development.

Do not bypass the skill for small UI changes.

Use browser/visual verification when available and do not claim verification that was not performed.
