# Claude Code Adapter

For every UI/UX task, apply the repository's `design-system-enforcer` skill.

Before modifying UI:
- read `DESIGN.md`;
- inspect existing design tokens and reusable components;
- preserve existing product behavior;
- implement using the documented design system;
- perform the skill's responsive, accessibility, and verification checks.

This applies to both new and ongoing development.

Do not duplicate the full skill in this instruction file.
