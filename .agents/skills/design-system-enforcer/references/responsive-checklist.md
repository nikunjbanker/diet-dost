# Responsive UI Checklist

Use after implementing or modifying responsive UI.

## Check

- [ ] Relevant mobile viewport
- [ ] Relevant tablet viewport
- [ ] Relevant desktop viewport
- [ ] Wide viewport where applicable
- [ ] No unintended horizontal scrolling
- [ ] Navigation remains usable
- [ ] Content hierarchy remains coherent
- [ ] Typography follows DESIGN.md
- [ ] Spacing follows DESIGN.md
- [ ] Cards/components do not become unusably narrow
- [ ] Tables have intentional overflow behavior
- [ ] Dialogs/modals remain usable
- [ ] Forms remain usable
- [ ] Buttons and touch targets remain usable
- [ ] Images/media scale or crop intentionally
- [ ] Breakpoints follow DESIGN.md or existing project conventions
- [ ] No mobile-only or desktop-only behavior was invented without need

## Evidence

Only claim a viewport was verified if it was actually inspected using the available browser/device tooling.
