# Visual Verification

Use when browser or visual tooling is available.

## Procedure

1. Start the application.
2. Open the changed page/flow.
3. Inspect the rendered result.
4. Compare against applicable DESIGN.md rules.
5. Check representative states.
6. Check relevant responsive viewports.
7. Correct deviations.
8. Re-check after correction.

## Verify

- typography
- colors
- spacing
- radii
- borders
- shadows/elevation
- component composition
- hierarchy
- interaction states
- responsive behavior
- accessibility-visible behavior

## Evidence rule

Do not claim visual verification from source-code inspection alone.

Do not use generated conceptual images as evidence that the application UI works.
